# Next Steps Learning Roadmap

## 1) Repo hygiene
- Meaningful commits
- Pull request discipline
- Small, reversible changes

## 2) Core engineering workflow
- Linting + formatting
- Automated tests
- CI checks on pull requests

## 3) Architecture fundamentals
- Domain vs infrastructure boundaries
- Config and secret management
- Error handling and logging strategy

## 4) Team readiness
- Onboarding docs for newcomers
- Runbook notes for common tasks
- Clear issue templates

## 5) Suggested progression
1. Ship one tiny feature end-to-end.
2. Add one integration test.
3. Add basic metrics/logging.
4. Document tradeoffs and refactor with intent.
